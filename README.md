# Course Management API

A robust RESTful API backend built with **Node.js**, **Express.js**, and **MongoDB** for managing courses, user authentication, and role-based access control.

---

##  Tech Stack
* **Runtime:** Node.js
* **Framework:** Express.js
* **Database & ODM:** MongoDB, Mongoose
* **Validation:** Zod
* **Authentication:** JSON Web Tokens (JWT), bcryptjs
